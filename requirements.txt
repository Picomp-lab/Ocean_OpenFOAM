# ── torch 系：从 pytorch 的 cu130 源取 ──────────────────────────────────────
# 集群是 CUDA 13（dgxh 的 H100/H200、ampere 的 A40）。PyPI 上同样叫 2.11.0 的
# torch 是 cu12 轮子，装上去计算节点 torch.cuda.is_available() 是 False。
#
# 这里**故意不写 +cu130**。原因（2026-08-20 用 pip --dry-run 实测过）:
#   · 写 torch==2.11.0 时，两个源都有候选，但 PEP 440 规定本地版本号排序高于同基
#     版本，2.11.0+cu130 > 2.11.0，pip 必取 cu130 那个 —— 与旧的 --index-url 写法
#     结果完全一致，是规范保证不是巧合。
#   · 写 torch==2.11.0+cu130 反而会坏事：wheel 装完后 dist 元数据里的版本被剥成
#     2.11.0（+cu130 只留在 torch.__version__ 里），pip 每次都判定"没装"，于是
#     每跑一次 setup.sh 就重下 2 GB。
# setup.sh 另有一条检查比对 torch / torchvision 的构建标是否一致，混装了会警告。
--extra-index-url https://download.pytorch.org/whl/cu130
torch==2.11.0
torchvision==0.26.0
